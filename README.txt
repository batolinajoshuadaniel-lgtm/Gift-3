MY PRINCESS — WEBSITE

1. Extract the ZIP file.
2. Open index.html in a browser (Chrome, Edge, Safari, etc.).
3. The page works locally; an internet connection is only needed for the optional Google Fonts.
4. Use the ไทย / EN button in the top-right corner to switch between English and Thai.
5. Tap any photo to open the photo viewer. Use the arrow buttons or keyboard arrows to move between photos.
6. The final button creates a floating-heart animation.

To personalize the message, edit the English and Thai text in index.html. Keep the data-en and data-th attributes together so both language versions stay in sync.
